---
title: Use cases
description: Practical ways to reuse, contextualize, and continuously improve AI skills.
---

Skillplane is useful when guidance should outlive one prompt, one conversation, or one agent runtime.

## Team standards

Turn review checklists, release procedures, research methods, or support playbooks into shared skills. Agents retrieve the same published instructions instead of relying on copied prompts that drift between tools and people.

## Project-aware agents

Keep the skill portable and attach project-specific facts as a context. One review skill can be paired with separate contexts for different repositories, customers, or environments without forking the core instructions.

## Composed workflows

An agent can discover and retrieve several focused skills for one job—for example, a research skill, a writing standard, and a publication checklist. Smaller skills remain easier to reuse and improve than one large all-purpose prompt.

## Continuous improvement

Let an agent record what it learned during real work and propose a candidate revision with evidence, confidence, validation results, and provenance. Review the exact file changes before publishing the next version.

## Human-controlled automation

Use review-required policy for every proposed change, or allow narrowly trusted agent credentials to auto-publish within limits such as semantic-version bump, allowed context, and daily count. Service credentials still cannot approve candidates or rewrite policy.

## Auditable delivery

Retrieve an exact immutable version and its digest when reproducibility matters. Version history, diffs, actor identity, declared agent/model metadata, and context revision identity make it possible to trace what an agent used and why a change was accepted.
