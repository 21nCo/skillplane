## Issue summary

Linear's OAuth client identifier is an HTTPS client-metadata document. Hydrating that document in Cloudflare Workerd failed because the native `fetch` function was stored on the OAuth runtime object and later invoked as a property, which supplied the runtime object as the function receiver. Workerd rejected that receiver with an `Illegal invocation`, and the OAuth boundary translated the unexpected exception into `server_error`.
