## Issue summary

Skillplane instruments a newly created low-level McpFn protocol server for every HTTP request. PostHog's default MCP context enrichment adds a required `context` argument during `tools/list` and records ownership on that server instance. A later `tools/call` runs on a fresh instance without the ownership record, so the synthetic argument reaches McpFn's strict canonical validator and is rejected as an additional property. The same server-side behavior affects MCPJam and Claude.
