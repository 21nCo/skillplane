## Issue summary

Skillplane duplicated AuthFn by issuing, hashing, authenticating, rotating, and
revoking custom `sps_...` service-principal credentials. This change moves new
credential lifecycle and authentication to AuthFn API keys while retaining
workspace association, role, scopes, delegation, policy, and lifecycle audit
metadata in the Skillplane service-principal domain model. Existing `sps_...`
credentials remain available only through a documented compatibility path and
migrate to AuthFn on rotation.
