## Mutation tool schemas

| Tool | Required scope | Required control fields | Result |
|---|---|---|---|
| `skill_amend` | `skills:amend` | skill/base IDs, replay key, bump, file operations and expected digests, learning, caller | candidate/review/policy/publication identity |
| `context_knowledge_update` | `contexts:write` | skill/context selectors, expected revision, Markdown, metadata, replay key, caller | immutable knowledge revision |
| `context_note_upsert` | `contexts:write` | skill/context, optional note ID, required expected revision on update, title/Markdown/metadata, replay key, caller | immutable current note revision |

All schemas are object-rooted and strict. Tool annotations are mutating,
non-destructive, idempotent, and closed-world.

## Idempotency/concurrency matrix

| Case | Expected and observed result |
|---|---|
| exact amendment retry | same candidate ID; no duplicate version |
| changed amendment replay key | `IDEMPOTENCY_KEY_REUSED`; no extra revision |
| stale amendment base/digest | `SKILL_VERSION_CONFLICT`; no commit |
| exact knowledge retry | same knowledge revision ID |
| stale knowledge writer | `CONTEXT_REVISION_CONFLICT` plus current revision/ID |
| note create | revision 1 with null base |
| exact note retry | same note/current revision |
| two updates from revision 1 | one revision 2; one `NOTE_REVISION_CONFLICT` |
| cross-selected-context note ID | `NOTE_NOT_FOUND`; original unchanged |
| audit insert failure | `AUDIT_WRITE_FAILED`; mutation and R2 candidate rolled back |
