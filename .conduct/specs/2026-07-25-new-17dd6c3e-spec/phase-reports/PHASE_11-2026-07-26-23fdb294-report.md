## Search and pagination — PASS

- Search supports query, workspace, visibility, tags, cursor, and a default
  limit of 20 with maximum 100.
- Workspace and authorization predicates execute before full-text ranking.
- Unauthorized documents cannot affect scores, result counts, or cursors.
- Results expose stable skill/workspace identity, summary, tags, visibility,
  current published version, semantic version, and digest.

- Note pages sort by update time descending and stable ID.

  returns `CURSOR_FILTER_MISMATCH`.

## Exact version and digest proof — PASS

Retrieval never selects content by "latest available" after authorization.
The requested selector resolves exactly one immutable database version by
current ID, exact version ID, semantic version, or numeric revision.

Before content is returned:

1. the R2 repository verifies the object against the database digest;
2. Skillplane re-canonicalizes the stored archive;
3. recomputed digest must equal the selected version digest;
4. recomputed canonical bytes must equal the stored bytes byte-for-byte;
5. stable JSON for the recomputed manifest must equal the immutable database
   manifest;
6. `SKILL.md` must be present and valid UTF-8.

The passing integration proof establishes:

```text
skill_versions.content_digest
  == MCP version.digest
  == MCP version.manifest.digest
  == recomputed canonical archive digest
```

The returned instructions and file descriptors come from that same verified
archive. A forced R2 failure returns `R2_READ_FAILED`, includes no provider
error or instructions, and never substitutes another version.

## Asset behavior — PASS

- Path normalization rejects traversal, absolute paths, and backslashes before
  any R2 read.
- Safe text up to 128 KiB is returned as strict UTF-8.
- Safe binary up to 256 KiB is returned as base64.
- Larger content in `auto` mode returns a five-minute authenticated download.
- Explicit inline delivery over the applicable limit returns
  `ASSET_TOO_LARGE`.
- The signed grant binds workspace, skill, version, path, file digest, bundle
  digest, credential ID, parent request ID, complete caller declaration, and
  expiry.
- Download reauthenticates scope and resource, resolves the same exact version,
  reloads/verifies the canonical bundle, and checks the file digest again.
- A different valid credential receives `401`.
- The issuing credential receives byte-for-byte exact content with private
  no-store, attachment, nosniff, same-origin, and sandbox response headers.

## Audit fail-closed evidence — PASS

Each successful or denied tool execution receives a unique MCP request ID and
records:

- workspace;
- authenticated actor type and ID;
- authenticated user when present;
- credential kind and stable credential ID;
- OAuth client ID when applicable;
- complete caller declaration labeled `caller-declared`;
- tool, outcome, resource, skill, version, digest, context, error code, and
  latency;
- detailed-read retention class.

The audit row is committed before tool content is returned. Any audit-writer
exception, including an unexpected generic provider error, maps to
`AUDIT_WRITE_FAILED`. The injected failure test proves private instructions,
connection details, and bearer values are withheld.

Daily retrieval metrics preserve declared agent/model and skill/context
dimensions. They commit after the durable detailed event; a metric failure
records a safe bounded retry signal and cannot roll back the audit or fail an
otherwise audited read.

Migration `0012_service_principal_audit_identity.sql` allows organization-owned
service principals without delegated users to retain caller agent/model
dimensions. The integration proof records `actor_type=service_principal`,
`user_id=NULL`, and separate complete caller metadata without inventing a human
identity.
